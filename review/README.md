# review/

Frozen artefacts and adversarial review output.

**Belongs here:** PDFs frozen at a named point (submission, rebuttal, camera-ready),
each with the git commit it was built from; adversarial reviews of the manuscript,
whether solicited from colleagues or generated; and the written response to each point
raised, with the change that answered it or the reason none was made.

**Does not belong here:** working drafts, which live in `paper/`. A file enters this
directory when it is frozen and does not change afterwards. If it needs to change, a new
frozen artefact is added; the old one stays.

Empty. Nothing has been drafted or reviewed.
