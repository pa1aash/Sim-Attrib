# docs/

Operator-facing notes: decisions, their reasoning, and the questions still open.

**Belongs here:** `OPEN_QUESTIONS.md` (questions only the operator can answer, numbered
and carried across sessions), session notes, and records of decisions that would
otherwise be reconstructible only from commit archaeology.

**Does not belong here:** anything a reader needs in order to understand the *claims* —
that belongs in `audit/`. The split is deliberate: `audit/` is the evidentiary record
and is written to be adversarially read; `docs/` is the working conversation with the
operator.
